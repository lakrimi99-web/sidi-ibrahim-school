# Sidi Ibrahim Pioneer School Website

الموقع الرسمي لمدرسة سيدي إبراهيم الرائدة — بني بـ HTML5, CSS3, JavaScript مع قاعدة بيانات محلية IndexedDB.

## 🌐 الوصول للموقع

الموقع يعمل مباشرة بدون خادم — فقط افتح `index.html` في المتصفح.

## 🔐 لوحة التحكم

الوصول عبر المسار `/admin` أو ملف `admin_login.html`

- **اسم المستخدم:** `sidibrahim`
- **كلمة المرور:** `159`

## 📁 هيكل المشروع

```
├── index.html          # الصفحة الرئيسية
├── news.html           # الأخبار والإعلانات
├── post.html           # تفاصيل المقال
├── contact.html        # اتصل بنا
├── about.html          # عن المدرسة
├── gallery.html        # معرض الصور
├── admin_login.html    # تسجيل دخول الإدارة
├── admin_dashboard.html # لوحة التحكم
├── admin_add_post.html  # إضافة/تعديل مقال
├── assets/
│   ├── css/style.css   # التصميم الشامل
│   ├── js/db.js        # قاعدة البيانات المحلية IndexedDB
│   └── js/main.js      # منطق التطبيق
├── uploads/            # صور المقالات
└── Push_To_GitHub.bat  # رفع التعديلات تلقائياً
```
